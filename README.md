# NakitAkıllı - Hackathon'26

Agentic KOBİ Finansal Yönetim Platformu.

## Özellikler
- **FastAPI Backend**: SQLite ile hızlı ve hafif veritabanı yönetimi.
- **Next.js 16 Frontend**: Modern, hızlı ve SEO uyumlu arayüz.
- **shadcn/ui & Tailwind v4**: Premium ve özelleştirilebilir tasarım.
- **AI Entegrasyonu**: Yakında!

## Kurulum
1. `backend` dizininde `.venv` oluşturun ve bağımlılıkları yükleyin.
2. `frontend` dizininde `npm install` çalıştırın.
3. `npm run dev` ile başlatın.
